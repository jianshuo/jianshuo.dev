# 封面须知（预置模板，科普书 / 小说用；绘本的封面随页图同一份清单出，不用这份）

你负责给一本书画封面并上传。派活消息里给了你：**工作目录**（下文 `<工作目录>`）、**skill 目录**（下文 `<skill 目录>`）。

## 先读

- `<skill 目录>/paint/SKILL.md` —— 出图说明书（命令、选项、退出码、错误码），**动手前读完**。
- `<工作目录>/book.json` —— 取 `slug`、`title`、`subtitle`、`author`（没有这个字段就是不署名）、`tint` / `dark`（配色）、`type`（气质）。
- `<skill 目录>/wjs-voicedrop-writing-book/SKILL.md` 的「封面 cover.jpg」一节和「形象铁律」一节 —— 硬规则以它为准。

## 要点（细则见上面那一节）

- **平面封面**：画的是封面这一面本身，正对镜头、满版、四边到头。不画成立体的书：没有书脊、厚度、透视、投影、桌面背景。
- **文字是主角**：主标题非常大、占上部约满宽；副标题约一半大小紧跟其下；有作者才写作者，放底部居中。背景是随书配色的抽象画面，留白充足。
- **文字让出图模型直接画进图**：提示词里一字不差列出书名、副标题、作者，并写明「画面上只允许出现这些文字，不要多余字符、水印、乱码」。不用任何本地叠字 / 改图工具。
- **形象**：主人没点名的角色形象一个都不引入；真需要一个形象时用汪汪。
- 一条前台命令，Bash timeout 给 600000：

  ```bash
  /opt/claude-agent/bin/paint "<提示词>" <工作目录>/cover.jpg --size 1024x1536 --group <slug>
  ```

  退出码 3 = 还没画完，**原样重跑同一条命令**接着等（不会重复画）。不丢后台、不自己 `--engine` 换引擎。

## 验图再上传

用 Read 看 `<工作目录>/cover.jpg`：书名、副标题、作者**逐字核对**，错一个字、多出乱码、或画成了立体书，就改提示词重画（重画加 `--force`）。合格后上传：

```bash
node <skill 目录>/wjs-voicedrop-writing-book/build.mjs asset <工作目录> cover.jpg cover.jpg
```

确认输出是 `ok`。最后只回复：封面是否已上传、用的哪个引擎、重画了几次；如果出图失败，把 paint 打印的错误码原样带回。
