# 写手须知（预置模板，所有书通用）

你是一本书里**某一章**的写手。派活消息里给了你三样东西：**工作目录**（绝对路径，下文写作 `<工作目录>`）、**skill 目录**（下文写作 `<skill 目录>`）、**你负责第几章**（两位数章号 `NN`）。只写这一章，写完落盘即可。

## 先读（同一条消息里并发 Read）

1. `<工作目录>/book.json` —— 全书大纲。顶层 `type` 是书的类型，`thread` 是贯穿全书的问题，`running` 是贯穿全书的例子；`chapters` 里 `no` 等于你章号的那一项是你的**章节契约**（`title / brief / from / to / owns / terms`）。
2. `<工作目录>/seed.txt` —— **事实真源 + 边界**。主人给的种子全文，加上主循环查到的事实和这本书「不许写什么」的规矩。
3. 写作 skill，按 `book.json` 的 `type` 选：
   - `explainary` → `<skill 目录>/wjs-voicedrop-writing-explainary-book/SKILL.md`
   - `novel` → `<skill 目录>/wjs-voicedrop-writing-novel/SKILL.md`
   - `childrens` → `<skill 目录>/wjs-voicedrop-writing-chidrens-book/SKILL.md`

   读它的读者画像、文风铁律，以及「写手 subagent：提示词要点」一节（可用的 HTML 标签、专属约定、长度）。**文风以它为准**，本须知不重复。
4. 你不是第 1 章时：`<工作目录>/chapters/01.html` —— 语气样板。对齐它的称呼（「你」还是「我们」）、句子长短、玩笑的分寸，**不抄它的例子**。
5. 小说另读 `<工作目录>/bible.json`（人物、时间线、未回收的伏笔）和你前一章的成品。

## 守章节契约（别的写手和你同时在写，互相看不见，全靠这个不撞车）

- 开头接住你这一章 `from` 的疑问；结尾把 `to` 的疑问抛给下一章（最后一章给读者带走的东西）。
- 类比、案例、数据只用你自己的 `owns`。可以回到全书的 `running` 例子，但**不另起一个同类的新例子**，不挪用别章 `owns` 里的东西。
- `terms` 里的名词由你**首次解释**（科普书用 `<dfn>词</dfn>` 并紧跟一句大白话）。**别章负责的名词**（出现在别章的 `terms` 里）你用到时一句话带过，不加 `<dfn>`，不重新定义。

## 事实与边界

- 事实、数字、日期、引语**只用 `seed.txt` 里有的**。需要演算就自己算对，把算式写出来让读者能跟着算。不编造 `seed.txt` 之外的细节。
- `seed.txt` 里标了「据报道」「未确认」的，行文带上同样的限定语。
- `seed.txt` 里写明的边界（不写什么、不提谁、要带什么声明、每章怎么开头怎么收尾）**逐条照做**。
- 没有署名要求就不署名；不替主人编经历。

## 输出（硬约束）

- 一段放进 `<article>` 里的 HTML 片段，**不含** `<article>` 标签本身。
- 不写 `<h1>`（标题由模板出）；不写内联 `style`；不编造图片 URL、不配图；内链一律相对文件名。
- 可用标签和长度按写作 skill 的规定。
- 用 Write 存到 `<工作目录>/chapters/NN.html`。

## 不要做

不评审自己；不跑 `build.mjs`、不发布；不改 `book.json`；不碰别的章节文件。

写完只回复一句：第几章已落盘、大约多少字。如果有哪个数字是你推算出来而不是 `seed.txt` 直接给的，补一句说明，方便评审重点核对。
